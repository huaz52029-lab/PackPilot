# PackPilot 安全说明

## 威胁模型

PackPilot 处理的是**不可信的压缩包**。攻击者可能通过恶意压缩包尝试：

1. 向目标目录之外写入文件（Zip Slip / 路径穿越）；
2. 覆盖系统或用户文件（例如 `C:\Windows\System32\...`、UNC 共享路径）；
3. 通过符号链接/硬链接跳出目标目录；
4. 通过超高压缩率内容耗尽磁盘（解压炸弹）；
5. 触发超长路径或非法文件名导致异常行为。

## 具体防护

### 1. 路径校验（解压前）

对每个待解压条目：

1. 规范化名称（统一使用 `/`，去除 `./`）；
2. 拒绝空名、控制字符、空字符、Windows 非法字符 `< > : " | ? *`；
3. 拒绝绝对路径、盘符路径（`C:\...`、`C:file`）与 UNC 路径（`\\server\share`）；
4. 拒绝任何 `..` 上级目录引用；
5. 拒绝 Windows 保留设备名（`CON`、`PRN`、`AUX`、`NUL`、`COM1-9`、`LPT1-9`）；
6. 拒绝以空格或点结尾的目录名（避免 Windows 静默改名导致越界）；
7. 计算最终输出路径，并与目标目录比较，确认其位于目标目录内部；
8. 任一条目不通过即**整体拒绝**该次解压，写入日志并弹出安全警告。

最后一步使用 `os.path.abspath + normpath + normcase` 后再比较，避免 `..` 与符号链接造成的绕过。

### 2. 不默认覆盖

目标文件已存在时不会静默覆盖：

- 默认策略为“重命名冲突文件”（`名称 (1).ext`）；
- 也可显式选择覆盖、跳过或“遇到冲突即停止”；
- 冲突判定在写入前完成，读写均使用独占创建（`xb`）避免竞态覆盖。

### 3. 符号链接与设备条目

- TAR：`issym()` / `islnk()` / 字符设备 / 块设备 / FIFO 条目默认跳过并记录提示；
- 7Z：符号链接条目不参与解压（不写入目标目录），并计入“已跳过”；
- PackPilot 自己创建的压缩包不写入符号链接（`dereference=True`，写入真实内容）。

### 4. 解压炸弹与资源限制

默认阈值（可在设置中放宽，但 Zip Slip 防护始终生效）：

| 指标 | 告警 | 阻止 |
| --- | --- | --- |
| 压缩率（解压后 / 压缩后） | ≥ 100:1 | ≥ 1000:1 |
| 解压后总大小 | ≥ 4 GB | ≥ 64 GB |
| 条目数量 | ≥ 200 000 | — |
| 单条目路径长度 | > 259 字符提示 | > 32 000 字符拒绝 |

7Z 解压还会把 `max_extract_size` 传递给 py7zr，由其内部限制解压总量。

### 5. 磁盘空间

解压前统计所需空间并与目标磁盘剩余空间比较（默认预留 2% 余量），不足时：

```text
⚠ 磁盘空间不足，已阻止开始任务：需要空间：7.80 GB，当前剩余：4.10 GB
```

任务不会开始，用户文件不会被部分写入。

### 6. 超长路径

Windows 上超过 260 字符的路径会先尝试普通创建，失败后自动使用扩展长度路径前缀（`\\?\`）重试；
仍失败则报告明确错误。

### 7. 临时文件

- 打开压缩包内文件时解压到 `%TEMP%\PackPilot\open\<uuid>`；
- 使用 `ShellExecuteEx` 获取默认程序进程句柄，程序退出后清理该目录；
- 若文件仍被占用（例如程序延迟释放），由定时器持续重试，并在应用退出与下次启动时继续清理；
- 启动时清理超过 24 小时的残留目录。

### 8. 权限

- 不请求管理员权限；
- 文件关联与右键菜单只写入 `HKEY_CURRENT_USER`；
- 安装程序使用 `PrivilegesRequired=lowest`（当前用户安装）。

### 9. 密码

- 不自行实现加密算法；
- 7Z 使用 py7zr 提供的 AES-256（可加密文件头）；
- 加密 ZIP 只能读取传统 ZipCrypto，AES ZIP 会明确提示不支持；
- 密码仅保存在内存中（当前会话的密码缓存），不会写入配置文件或日志。

## 已知限制

- 解压炸弹防护基于压缩率与总大小估算，无法覆盖所有构造方式（例如多条目分布式膨胀），
  因此仍建议只解压来源可信的压缩包；
- TAR 格式不提供逐条目 CRC，测试只能校验压缩流完整性与可读性；
- 标准库不支持 AES 加密 ZIP 的解压与所有加密 ZIP 的写入。
